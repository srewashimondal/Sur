# Sur

**Sur** is a Bangla music analytics project designed to explore how different genres vary based on measurable audio characteristics. The project uses a Kaggle dataset containing 1,742 Bangla songs across six genres: Adhunik, Band, Hip-Hop, Nazrul, Palligeeti, and Rabindra. Each song includes features such as tempo, RMSE, spectral centroid, spectral rolloff, chroma frequency, zero crossing rate, and MFCC values. I created Sur because of my personal connection to Bengali music and my interest in learning more about the musical patterns behind different styles of Bangla songs.

Python and pandas were used to clean, explore, and enrich the dataset. I checked for missing values and duplicates, created new tempo and energy categories, calculated genre-level summaries, and analyzed correlations between audio features. The analysis showed clear differences across genres. For example, Hip-Hop had the highest average energy and the largest percentage of high-energy songs, while Rabindra songs were generally softer and had the lowest share of high-energy tracks. Band music had the highest average spectral centroid, suggesting a brighter sound profile, while Rabindra songs had the highest average tempo in the dataset.

The cleaned data was loaded into a SQLite database containing a `songs` table with all 1,742 records. SQL queries were written to compare song counts, tempo, energy, brightness, and category distributions across genres. The SQL analysis included grouping, sorting, conditional aggregation, percentages, and top-song rankings. These queries made it possible to identify the fastest and slowest songs, compare high-energy percentages, and determine which genres had the strongest average audio characteristics.

Tableau was used to build an interactive dashboard titled **Sur: Bangla Music Genre Analytics**. The dashboard visualizes song counts, average tempo, average energy, spectral brightness, and energy categories by genre. The project currently demonstrates an end-to-end analytics workflow using Python, SQL, SQLite, and Tableau, with Power BI planned as the next phase. Future improvements may include adding singer information, gender, release year, popularity, mood, karaoke availability, and recommendation features to help users discover Bangla songs based on their interests.
